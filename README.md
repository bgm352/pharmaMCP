This app is a **“Pharma MCP Agent Readiness Auditor”** that scores pharma websites on how usable they are as MCP-style tools for AI agents across five pillars: manifests, callable endpoints, structured data, medical authority, and context quality. It crawls each site, probes known MCP/OpenAPI paths, detects medical schema and API patterns, classifies readiness (AGENT_READY, PARTIAL, NOT_READY), suggests top engineering fixes with point gains, and optionally generates Claude-based MCP integration recommendations plus CSV/PDF exports for multi-domain benchmarking.
